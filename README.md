
# SOLOSTORE

Projeto realizado para as disciplinas de Projeto Integrador II e Desenvolvimento Web.

## Conceito

trabalho utilizando **HTML** e **CSS Inline** para prototipar um e-commerce que será aprofundado nos seguintes semestres, neste primeiro projeto foram utilizados assests da loja oficial da NIKE apenas para fins de exemplo, não havendo nenhuma relação ou utilização comercial destes elementos fora do ambito academico
